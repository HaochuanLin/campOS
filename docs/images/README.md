# Documentation figures

This directory is reserved for reviewed figures generated by the simulation.

Before adding an image:
1. Generate it from a documented command and configuration.
2. Keep the corresponding CSV output and run settings available for review.
3. Record the synthetic site, mode, and whether the run used `--quick`.
4. Do not present synthetic output as field measurements.

No result images or source CSVs were present in the original attachment, so this directory intentionally contains no fabricated figures. Add figures only after they have been generated and checked.
